# 2markdown - 文档转换网站

一个基于[MarkItDown](https://github.com/microsoft/markitdown)的在线文档转换平台，可以将PDF、Word、Excel、PowerPoint等常见格式文件转换为Markdown格式。

## 功能特点

- 支持多种文档格式转换为Markdown，包括PDF、Word、Excel、PowerPoint等
- 用户友好的界面，简单易用
- 安全的文件处理机制
- 快速准确的转换效果

## 技术栈

- 前端：HTML、CSS、JavaScript、Vue.js
- 后端：Python、Flask
- 文档转换：MarkItDown

## 本地开发设置

1. 克隆仓库

```bash
git clone https://github.com/yourusername/toMarkdown.git
cd toMarkdown
```

2. 安装依赖

```bash
pip install -r requirements.txt
```

3. 运行开发服务器

```bash
python app.py
```

4. 访问 http://localhost:5000 开始使用

## 使用方法

1. 访问网站首页
2. 上传需要转换的文件
3. 选择输出格式（可选项）
4. 点击"转换"按钮
5. 下载转换后的Markdown文件
